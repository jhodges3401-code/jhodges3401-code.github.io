FAQ

How much does Atlassian Statuspage cost?

Atlassian Statuspage public pages cost $29, $99, $399 or $1,499 a month. Hobby is $29 a month (250 subscribers, 5 team members, 5 metrics, email, Slack, and Teams notifications, custom domain). Startup is $99 a month (1,000 subscribers, 10 team members, 10 metrics, email, SMS, and webhook notifications, custom CSS, REST API). Business is $399 a month (5,000 subscribers, 25 team members, 25 metrics, custom CSS, HTML, and JS, component subscriptions). Enterprise is $1,499 a month (25,000 subscribers, 50 team members, 50 metrics, role-based access control). Atlassian Statuspage has a free plan (100 subscribers, 25 components, 2 team members, no custom domain). Yearly card billing needs a signed order form. Private and audience-specific pages are priced separately.

Is Okayline a one-time payment?

Yes. $99 once for the Pro template. Hosting on GitHub Pages is free for public repos.

Is there a free version?

Yes. Okayline Lite is MIT-licensed on GitHub.

Are there free alternatives to Atlassian Statuspage?

Yes. Atlassian Statuspage has a free plan (100 subscribers, 25 components, 2 team members, no custom domain). Open-source options are worth a look too: Upptime (MIT) also runs on GitHub Actions and Pages and is the closest free match; Gatus (Apache-2.0) and Uptime Kuma (MIT) are self-hosted apps you run on your own server or container; cState (MIT) is a static Hugo status page you update yourself. Our own Okayline Lite (MIT) is a free manual-status page. What the $99 gets you: a dependency-free template (Node 20, no npm install) set up from one config file, automatic checks about every 5 minutes, 90-day uptime bars, Markdown incidents and scheduled maintenance, a fill-in form at /admin for posting incidents, RSS, a JSON API and a status badge, plus a 14-day refund. If a free tool already does what you need, use it.

Does Okayline cost anything beyond $99?

Not if your status repo is public: GitHub Pages and Actions are free there. GitHub Pages on a private repo needs a paid GitHub plan, and a custom domain costs whatever your registrar charges.

Is Okayline affiliated with Atlassian Statuspage?

No. It's an independent product built from scratch.
